# UI Design — Cooking Mama PWA

**Tanggal:** 2026-06-24
**Status:** Disetujui

## Ringkasan

Desain ulang tampilan publik (bukan admin Filament) menjadi UI mobile-first yang hangat & nyaman, mengaktifkan Tailwind CSS v4 yang sudah terpasang namun belum terhubung, dan mengganti semua class CSS kustom lama dengan Tailwind utility classes.

## Keputusan Desain

| Keputusan | Pilihan |
|-----------|---------|
| Gaya visual | Hangat & nyaman (warm & cozy) |
| Target utama | Mobile-first (HP) |
| Navigasi | Bottom navigation bar |
| Pendekatan styling | Pure Tailwind utility classes |

## File yang Diubah

### 1. `resources/views/components/layout.blade.php`
- Tambah `@vite(['resources/css/app.css'])` di `<head>` — ini yang mengaktifkan Tailwind.
- Tambah `<header>` hijau sage dengan logo "🍳 Cooking Mama" dan judul.
- Tambah `<nav>` bottom navigation (Cari / Resep / Favorit) dengan ikon emoji.
- Set `class="min-h-screen bg-amber-50 font-sans"` pada `<body>`.
- Bungkus `$slot` dengan padding bawah agar konten tidak tertutup bottom nav.

### 2. `resources/views/home.blade.php`
- Tambah teks sambutan singkat di bawah komponen RecipeFinder.

### 3. `resources/views/livewire/recipe-finder.blade.php`
Ganti semua class kustom dengan Tailwind:
- Input bahan: `input` putih dengan border `stone-200`, rounded, focus ring hijau.
- Chips bahan: pill `bg-green-100 text-green-800 rounded-full px-3 py-1` dengan tombol `×`.
- Tombol **Cari Resep**: `bg-green-700 text-white w-full rounded-xl py-3 font-bold`.
- Tombol **Eksplor dengan AI**: `bg-orange-50 text-orange-600 border border-orange-200 w-full rounded-xl py-3 font-bold`.
- Loading state AI sudah ada via `wire:loading` — pertahankan.
- Kartu hasil: `bg-white rounded-xl shadow-sm p-4` dengan badge persentase.
  - Badge ≥80%: `bg-green-100 text-green-700`
  - Badge 50–79%: `bg-amber-100 text-amber-700`
- Teks "Kurang: ..." dalam warna `stone-400`.

### 4. `resources/views/recipes/show.blade.php`
- Gambar resep: `rounded-2xl w-full object-cover h-48 bg-amber-100`.
- Info servings dalam pill abu-abu kecil.
- Daftar bahan: pill `bg-stone-100 text-stone-700 rounded-lg px-2 py-1 text-sm`.
- Langkah memasak: `<ol>` dengan nomor dalam lingkaran `bg-green-700 text-white rounded-full`.
- Tiap langkah dalam `<li>` dengan `flex gap-3 items-start`.

### 5. `resources/views/livewire/recipe-rating.blade.php`
- Bintang: `text-amber-400 text-2xl` untuk yang aktif, `text-stone-300` untuk yang kosong.
- Tombol bintang disabled setelah rating diberikan (sudah ada logiknya, tinggal styling).
- Pesan terima kasih dalam `text-green-700 font-medium`.

## Yang Tidak Diubah

- Logika Livewire (`wire:model`, `wire:click`, `wire:loading`) — semua dipertahankan.
- Struktur HTML/elemen — hanya class yang diganti.
- Admin Filament (`/admin`) — di luar scope.
- `app.css` — sudah benar (`@import 'tailwindcss'`), tidak perlu diubah.
- `welcome.blade.php` — halaman default Laravel, tidak dipakai di routing utama.

## Catatan Teknis

- **`@vite` wajib ada** di layout agar Tailwind v4 aktif. Tanpa ini tidak ada styling sama sekali.
- Bottom nav "Favorit" belum ada fiturnya — tampilkan saja ikonnya, tidak ada link aktif. Tandai sebagai fitur pengembangan di `docs/ROADMAP.md`.
- Emoji dipakai sebagai ikon visual ringan — tidak perlu library ikon tambahan.
- Placeholder gambar (`/images/recipe-placeholder.png`) sudah ada — tetap dipakai jika `image_url` null.
